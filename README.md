# GitHub Follower Manager

A simple, manually-triggered Python script to help you manage your GitHub following list. 

It automatically:
- **Follows back** users who follow you.
- **Unfollows** users who don't follow you back.
- **Ignores** Organizations (so you don't accidentally unfollow the orgs you want to track).

## Prerequisites

- **Python 3.x** installed on your computer.
- The `requests` Python library.
